# Kanka Dili Test Dosyalari

Bu klasor, Kanka programlama dilinin Turkce sozdizimi icin test dosyalarini icerir.
Dosya uzantisi: `.knk`

## Turkce Anahtar Kelimeler

| Ingilizce | Turkce     |
|-----------|------------|
| `var`     | `degisken` |
| `print`   | `yazdir`   |
| `if`      | `eger`     |
| `else`    | `degilse`  |
| `while`   | `iken`     |
| `for`     | `icin`     |
| `fun`     | `fonk`     |
| `return`  | `dondur`   |
| `true`    | `dogru`    |
| `false`   | `yanlis`   |
| `nil`     | `bos`      |
| `and`     | `ve`       |
| `or`      | `veya`     |
| `class`   | `sinif`    |
| `super`   | `ust`      |
| `this`    | `bu`       |

## Test Dosyalari

| Dosya                    | Konu                              |
|--------------------------|-----------------------------------|
| `01_degiskenler.knk`     | Degisken tanimlama ve atama       |
| `02_aritmetik.knk`       | Aritmetik islemler ve stringler   |
| `03_kosullar.knk`        | if/else kosul ifadeleri           |
| `04_donguler.knk`        | while ve for donguleri            |
| `05_fonksiyonlar.knk`    | Fonksiyonlar ve rekursiyon        |
| `06_kapsam.knk`          | Degisken kapsam kurallari         |
| `07_mantik_ve_bool.knk`  | Boolean degerler ve mantik        |
| `08_saat_native.knk`     | Native `clock()` fonksiyonu       |

## Calistirma

```
java com.kankaLang.kanzi.Kanka tests/01_degiskenler.knk
```
